# Парикмахерская

Приложение для работы с базой данных `HairdresserDB` в SQL Server.

## Запуск

1. Убедитесь, что SQL Server Express запущен и база `HairdresserDB` создана.
2. Откройте PowerShell в этой папке.
3. Установите компонент подключения: `pip install -r requirements.txt`.
4. Запустите программу: `python app.py`.

В программе доступны просмотр и добавление клиентов, мастеров, услуг и записей, а также отчёт по выручке мастеров.
